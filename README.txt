GreenScape - Garden Maintenance HTML Template
=============================================

Professional ready-to-use HTML website template for garden care, lawn maintenance, 
landscaping and outdoor service companies.


FEATURES
--------
- 6 fully responsive pages
- Modern clean design
- Bootstrap 5.3
- Mobile-friendly
- Easy to customize
- Working contact form (frontend)
- SEO-friendly structure
- Fast loading


PAGES INCLUDED
--------------
1. Home (index.html)
2. Services
3. Portfolio
4. Pricing
5. About
6. Contact


TECHNOLOGIES
------------
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript


HOW TO USE
----------
1. Download and unzip the files
2. Open index.html in your browser
3. Replace texts, phone numbers, email and images with your own
4. Upload all files to your web hosting


CUSTOMIZATION
-------------
Main colors can be changed in style.css inside the :root section:

--primary: #2d6a4f;
--primary-dark: #1b4332;
--primary-light: #40916c;

index.html

portfolio.html

contact.html
style.css
main.js
README.txt
